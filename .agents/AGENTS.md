# Workspace Rules — Envoy Rainmaker Flight Time Converter

Read `AGENTS.md` at the repository root and follow it.
- Trigger `"go"` (or any request to process/convert PDFs): run `./run.sh` on Mac/Linux or `run.bat` on Windows.
- Deadhead legs (`DHD-A\OA_DHD` and variants) are excluded from flight time.
